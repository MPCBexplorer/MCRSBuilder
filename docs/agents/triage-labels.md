# Triage Labels

This repo uses the default triage label vocabulary:

| Label             | Meaning                                      |
|-------------------|----------------------------------------------|
| `needs-triage`    | New issue, needs initial categorization      |
| `needs-info`      | More information required from requester     |
| `ready-for-agent` | Clear spec, ready for agent execution        |
| `ready-for-human` | Requires human decision or review            |
| `wontfix`         | Will not be addressed                        |

Labels are applied by the `triage` skill based on issue content.
